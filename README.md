# Finanças Bom Sabor

Crie um sistema web moderno, responsivo e visualmente profissional para gerenciamento financeiro da minha confeitaria chamada “Bom Sabor RS Confeitaria”.

O objetivo principal do sistema é me ajudar a controlar totalmente o financeiro da empresa e também separar corretamente os gastos pessoais dos gastos empresariais.

O sistema deve ter foco em:

controle financeiro realista

separação de dinheiro

organização diária simples

metas

controle de lucro

prevenção de prejuízo

crescimento saudável da empresa

IMPORTANTE: No passado tive prejuízos financeiros porque misturava todo o dinheiro da empresa com gastos pessoais. O sistema deve me ajudar a evitar isso e me mostrar claramente a situação financeira real da empresa.

Quero um sistema moderno, intuitivo, fácil de usar diariamente e com muitos gráficos visuais.
